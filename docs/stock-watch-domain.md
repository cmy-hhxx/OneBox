# 股票看盘领域模型

本文定义股票看盘的通用语言和跨存储、网络、UI 必须保持的业务不变量。实现边界见[架构](architecture.md)，视觉语义见[设计规范](design.md)。

## Instrument

**Instrument（标的）**是可以加入自选并接收行情的证券。它包含规范化代码、用户可见名称和一个 `SymbolNamespace`，并由 provider 无关的 `InstrumentID` 唯一标识：

```text
<namespace>:<canonical-symbol>
```

关键不变量：

- 身份由代码域和规范化代码共同决定，不由 provider 的临时行情标识、显示名称或列表位置决定。
- 名称去除首尾空白后必须为 1–128 个字符，不能包含控制字符或冒号。
- A股代码为六位 ASCII 数字；港股代码规范为五位数字并在左侧补零；美股代码为 1–16 位大写字母、数字、`.` 或 `-`。
- JSON 只表达 `symbol`、`name` 和 `namespace`；provider 标识不进入导入格式或持久身份。

## SymbolNamespace

**SymbolNamespace（代码域）**消除相同证券代码在不同交易所或市场中的歧义。支持值为：

| 值 | 含义 | 所属 Market |
| --- | --- | --- |
| `sse` | 上海证券交易所 | A股 |
| `szse` | 深圳证券交易所 | A股 |
| `bse` | 北京证券交易所 | A股 |
| `hk` | 香港交易所 | 港股 |
| `us` | 美股 | 美股 |

每个代码域只映射到一个 `Market`；多个 A股交易所代码域可以映射到同一个 Market。搜索结果、JSON 和旧数据在进入自选前都必须先形成有效、规范化的代码域身份。

## Market

**Market（市场）**汇总不参与证券身份、但决定展示和行情解释的规则。当前只有 A股、港股和美股，分别使用人民币、港币和美元展示，并按上海、香港和纽约时区解释交易日与分时时间。

`Market` 不替代 `SymbolNamespace`：例如沪市和深市都属于 A股，但 `sse:000001` 与 `szse:000001` 仍是不同标的。涨跌颜色按市场惯例解释，且必须同时提供箭头、符号或文字；完整规则见[设计规范](design.md#股票看盘)。

## Watchlist

**Watchlist（观察列表）**是一个有序的 `Instrument` 集合。

关键不变量：

- 同一个 `InstrumentID` 最多出现一次；顺序是用户数据并需要持久化。
- 添加重复标的不改变列表。导入中的重复身份按第一次出现的位置去重。
- JSON 导入是对整份列表的原子替换，不是增量合并；任一条目无效时不应用部分结果。
- 从列表移除标的时，同时移除只属于该标的的行情缓存和目标价提醒。
- 刷新批次以开始时的列表版本为准；列表在刷新中变化后，旧批次不能把已移除标的数据写回当前状态。

## QuoteSnapshot

**QuoteSnapshot（行情快照）**是一个 provider 对单个标的、单个市场交易日的完整可接受结果。它包含开盘价、昨收价、最新价、严格递增的分钟 OHLC、行情时间、OneBox 接收时间和来源。涨跌幅只以最新价相对昨收价计算。

关键不变量：

- 快照的 `InstrumentID` 必须与请求标的一致。
- 开盘价、昨收价、最新价和所有 OHLC 都必须是有限正数；每根分钟线的最高价和最低价必须包住开盘价与收盘价。
- 分钟时间不能重复或倒序，且必须属于按该市场时区计算的同一交易日。
- provider fallback 选择一份通过校验的完整快照，不拼接不同 provider 的不一致字段。
- 比当前已接受行情更旧的响应不得覆盖较新状态；请求失败、无数据或旧响应可以让现有缓存标为 stale，但不能伪装成实时行情。
- 只有按市场时区属于当前日历日的有效快照可以标为 live 并评估提醒；行情源成功返回的较早交易日结果标为 previousSession，正常展示报价和分时并标明实际行情日期，不计为刷新错误、不评估提醒，也不用于生成当前价格目标。未来交易日结果被拒绝。
- 周末、节假日或当天尚无新行情时，以行情源返回且不早于已接受快照的交易日为展示依据；当前没有交易所节假日表，不凭日期差声明市场休市或保证行情源已更新到最近一个交易所交易日。本地恢复后未经成功刷新的缓存，以及请求失败后保留的数据，仍标为 stale。
- 本地缓存只保留观察列表中每个标的最近接受的交易日快照；缓存是容错显示，不是及时性或准确性保证。

## AlertConfiguration

**AlertConfiguration（提醒配置）**定义股票看盘可见期间如何从新接受的快照产生本地提醒。它包含总开关、提醒依据，以及上涨和下跌阈值：

- **昨收涨跌幅**：全局上涨、下跌阈值均为 0.5%–15%。
- **目标价格**：每个观察标的可以有一个正数上涨目标、一个正数下跌目标，至少设置一侧才形成规则。

关键不变量：

- 百分比只相对快照的昨收价计算；目标价只比较同一标的的最新价。
- 每个标的独立记录触发状态。到达阈值只触发一次，价格回到阈值内的回差区域后才重新 armed，避免同一边界在连续刷新中反复提示。
- 配置或单标的目标变化会重置相关触发状态；关闭提醒不会保留正在显示的提醒。
- 上涨提醒使用牛叫，下跌提醒使用熊吼；两种声音可以分别关闭。颜色或声音都不是唯一状态表达。
- 提醒只由工具可见期间新接受的行情驱动，显示在 OneBox 内；它不是系统通知、后台监控或交易信号。

## 关系摘要

```text
SymbolNamespace ──映射到──> Market
       │
       └──与规范化 symbol 组成──> InstrumentID ──标识──> Instrument
                                                        │
Watchlist ──有序且唯一地包含────────────────────────────┘
                                                        │
QuoteSnapshot ──属于一个 Instrument 和一个交易日─────────┤
AlertConfiguration ──全局规则 + 每标的目标───────────────┘
```
