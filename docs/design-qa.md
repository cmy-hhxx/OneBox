# UI 验收

强制视觉契约见 [设计规范](design.md)。本文件只记录可复现步骤和当前未验证项；截图不进入版本库。以下人工路线是交付前待执行清单，不表示本次文档更新已经完成这些验证。

## 运行

1. 在 Apple Silicon 本机运行 `./scripts/check.sh`。
2. 从 Xcode 运行 `OneBox`，或启动 Debug 产物：
   - 默认窗口：`.build/DerivedData/Build/Products/Debug/OneBox.app/Contents/MacOS/OneBox --ui-default`
   - 最小窗口：`.build/DerivedData/Build/Products/Debug/OneBox.app/Contents/MacOS/OneBox --ui-minimum`
   - 宽屏和纵向窗口：从任一状态分别只增加宽度、只增加高度；`--ui-*` 只设置首次尺寸，不锁定宽高比。
3. 需要性能或内存证据时按变化范围另运行：
   - ASCII：`./scripts/benchmark-ascii.sh`
   - 股票看盘：`./scripts/benchmark-stock-watch.sh`
   - PodPin：`./scripts/benchmark-podpin.sh`

`--ui-dark`、`--ui-minimum` 和 `--ui-default` 只在 Debug 构建生效；深色只用于检查结构，不是产品外观或验收目标。隔离的 `--ui-testing` 由 Debug/Release UI 测试使用，但必须同时提供位于系统临时目录内的专用数据根；只有同时带上该隔离参数时，`--ui-reduce-motion` 才会在组合根注入测试专用 override，PodPin 路由以“override 优先、系统 Reduce Motion 兜底”计算同一个分支，且不修改系统偏好。固定 Apple Silicon 流程会先通过独立的 Release `OneBoxUI` scheme 执行 `OneBoxUITests` 确定性交互检查（包括 Reduce Motion push/pop 无横向位移），再使用隔离的 DerivedData 执行时序性能计划。Release 性能计划可再把测试 bundle 中的 PodPin 音频复制到该根后注入，既不读取用户数据，也不把 fixture 打进 Release App。Release package benchmark 在 `.build/Logs` 保留原始日志和 JSON 环境报告；`OneBoxPerformance` UI 测试计划保留 xcresult。

## 通用人工路线

- 默认、最小、横向加宽和纵向加高窗口：检查窗口能自由改变宽高、侧边栏折叠、三个工具即时切换，以及无截断、重叠、意外换行或水平滚动。
- 键盘：只用键盘走完当前工具主任务；确认快捷键不抢占文本输入。Escape 顺序必须是系统 sheet/popover → trailing inspector → PodPin drill-in → 根页面无操作；关闭检查器后焦点在下一运行循环恢复到发起控件。
- 辅助功能：用 VoiceOver 读出控件名称、状态、当前值、错误和不可逆影响；再检查 Voice Control、Switch Control 和 Full Keyboard Access。减少动态效果时检查 PodPin 路由没有横向位移，提醒和其他必要反馈只使用短淡变。

| 矩阵 | 必查状态 | 通过条件 |
| --- | --- | --- |
| 窗口 | 默认、最小、宽屏、纵向 | 可独立改变宽高；主内容与右侧 inspector 不覆盖、无水平滚动 |
| 标准 inspector | ASCII 参数、股票看盘 | 默认收起；首次打开后为原生 trailing 列固定 248pt；可快速反向开关；Escape 和关闭按钮均恢复焦点 |
| 队列 inspector | PodPin 正在播放 | 默认收起；首次打开后为原生 trailing 列 min 280 / ideal 320 / max 360pt；始终推挤播放器，不替换或覆盖它 |
| PodPin 路由 | 资料库 → 导入 → 正在播放 → 返回导入 | push 从右进入、pop 反向；返回后 URL、目标文件夹和分段选择草稿不丢失 |
| Reduce Motion | PodPin push/pop、检查器、提醒 | 路由最多 100ms 淡变且无横向位移；高频内容不随呈现动画移动 |
| 键盘 | 三工具主路径、Escape、返回 | 完整键盘可达，文本输入不被抢占，返回按钮语义与目的地一致 |
| VoiceOver | 检查器、PodPin 路由、确认和错误 | 名称、状态、错误和不可逆影响可读；关闭后焦点回到发起控件 |

## ASCII 工坊人工路线

- 检查默认品牌素材、导入、比例、配色、参数、播放、导出、拖放、平移、缩放和预览/导出构图一致。
- 持续拖到物理屏幕边缘后，内容仍可继续平移；松开或切走窗口后指针恢复正常。
- 画布聚焦时检查方向键、`+`/`-`、`0`、空格和 Escape；字符输入中的空格不触发播放。
- 新会话先确认动画为“关闭”且空闲时没有持续绘制；显式选择动画并播放后再检查动态效果。检查名称、状态、手势替代操作、窗口离屏/最小化/完全遮挡时暂停，以及关闭检查器后的焦点恢复。

## PodPin 人工路线

### 资料库与导入

1. 在默认和最小窗口选择 PodPin，打开集合面板并切换收件箱、最近导入、最近播放、已下载和层级文件夹；确认文件夹在同一块可展开树中选择，没有二、三级飞出菜单，选择后焦点回到集合按钮。检查新建、重命名、移动、删除、分页、空/加载/失败状态及底部播放条。
2. 导入 B 站、抖音、小宇宙和 Fireside 分享文字；覆盖单项归档并播放、B 站有序多分 P、目标文件夹、重复内容移动与刷新，以及可恢复错误。上下文菜单只能进入“移动到…”任务面板，导入、创建和移动均使用同一树形位置选择器。
3. 对需要浏览器挑战的来源先拒绝、再明确选择 profile；确认没有静默读取浏览器状态，失败不会写入半成品资料库项。
4. 确认 hover 操作也能通过键盘焦点或上下文菜单到达，列表标题、来源、时长、存储状态和实际听过区间在两种窗口尺寸中可读。

### 播放、下载与次级导航

1. 覆盖在线与离线播放、暂停/缓冲/重试、15/30 秒跳转、seek 后听过区间保留空隙、五档速率、音量和输出设备。
2. 检查待播队列重排、移除、清空、自动续播和失败重试；切换到其他工具后，已明确开始的播放或下载应继续。
3. 依次走完“资料库 → 导入 → 正在播放 → 返回导入”：push 从 trailing 进入，返回完全反向；回到导入页后 URL、目标文件夹和分段选择仍在。重复点击当前目的地不得重复 push，切换集合和导入成功必须回到资料库根页面。减少动态效果时用录屏或 Accessibility Inspector 确认只发生不超过 100ms 的淡变，没有横向位移。
4. 从正在播放打开待播队列；检查 `.queue` 原生右侧 inspector 推挤而不覆盖或替换播放器，在最小、默认、宽屏和纵向窗口都保持同一结构。快速反复点击可立即反向，Escape/关闭后 VoiceOver 焦点返回队列按钮；窄窗口仍保留“导入”文字，正在播放图标有完整辅助功能名称。
5. 确认 PodPin 没有设置按钮或设置页。没有当前音频时也能从紧凑播放条选择并持久化速率；播放中修改立即生效，正在播放页显示相同值。封面保持正常不透明度，遗留 `podpin.nowPlayingContentOpacity` 偏好不影响界面且不被主动删除。
6. 退出应用并重启，确认资料库、队列、播放位置、速率和音量已持久化；退出期间活动导入、下载、解析和播放会在期限内清理，未留下迟到写入。
7. 对打包了锁定媒体工具的 Release 产物完成真实下载，并检查离线文件可播放；未打包媒体工具的产物只验收在线播放和明确的下载不可用反馈。

### PodPin 性能路线

1. 首次打开和再次切走/切回各录制一次 SwiftUI Instrument 与 Hangs；热重入必须直接保留已有内容，不出现 loading 空白帧，缓存命中时首屏查询数为 0。
2. 分别用 1,000 和 10,000 节点 fixture 展开根与当前选中路径；确认只渲染扁平化后的可见行，并按 [工程规范](engineering.md) 达到 P95 门槛。
3. 在批量下载进度、播放进度和行情更新时开关 inspector 或路由；确认高频值没有继承 180ms 路由事务，首值、完成和失败立即出现。

## 股票看盘人工路线

### 窗口、长列表和颜色

1. 在默认和最小窗口选择“股票看盘”，分别展开和折叠宿主侧栏。检查 loading、成功内容、空列表和启动失败页面不会重复产品品牌或工具标题。
2. 确认检查器初始收起，再在最小、默认、宽屏和纵向窗口打开：始终使用原生右侧 248pt trailing inspector，不得覆盖行情表或产生水平滚动。窄行情行必须保留名称、代码/状态、价格和涨跌方向，仅隐藏分时；关闭后行情表恢复空间。
3. 用受控有效 JSON 建立足以滚动的长列表，连续滚动、选择、拖动排序、用检查器上下移和移除；确认行高、稳定列、选中底色和操作反馈不跳动，重进工具后顺序保持。
4. 对 A股/港股检查红涨绿跌，对美股检查绿涨红跌，对持平检查中性色。每个方向必须同时有正负号、箭头和 VoiceOver 文本。A股收盘复盘的 B/S 标记必须保持在图内并可读出含义。

### 错误、stale 和刷新

1. 完成一次成功刷新后切换到其他工具再返回；先恢复的缓存应明确显示“本地缓存”或 stale，不能伪装为实时数据。
2. 在受控断网下检查全量失败、恢复网络后的重试，以及部分 provider 失败；已成功缓存保留，工具条或对应行状态说明来源问题，界面不承诺恢复时间。
3. 用测试用用户目录或失败数据库 adapter 分别触发启动、观察列表写入、提醒写入和缓存清理错误；检查默认/最小窗口中的错误文案、优先级、重试或关闭提示。错误不显示搜索词、自选内容或完整请求，数据库路径只在专门诊断控件中展示。
4. 在工具刷新中切换到其他工具，确认视图 task 取消后没有新的搜索或行情请求，待保存提醒已 flush，数据库可再次打开。窗口只被遮挡、失焦或最小化不属于此路线的停机断言。

### 搜索和 JSON

1. 选择工具条“添加标的”并确认搜索框获得焦点；分别用名称和代码搜索 A股、港股、美股，检查同代码不同 `SymbolNamespace` 的显示。
2. 用 Return 提交，覆盖 loading、取消、空结果、网络失败、重试、重复添加和成功添加；Escape 关闭并确认焦点回到合理位置。
3. 打开 JSON 整体替换，检查“填入当前列表”和复制结果。分别提交空文本、非法 JSON、无效 namespace/代码/名称和重复标的；失败不得应用部分列表。
4. 对有效替换先取消 destructive confirmation，再确认一次；检查顺序按 JSON 保留，已移除标的的目标价和缓存消失。移除标的和清空缓存也必须分别确认且文案说明不可撤销范围。

### 提醒和数据诊断

1. 切换百分比与目标价依据，检查总开关、0.5%–15% 阈值、按现价生成目标、单标的上涨/下跌目标，以及无现价时的禁用或错误反馈。
2. 分别预览上涨和下跌提醒，检查牛/熊声音独立开关、方向图标和文字、按市场变化的颜色、6 秒自动消失，以及鼠标悬停或键盘焦点期间暂停。减少动态效果时只允许淡入淡出。
3. 只用键盘完成“添加标的”、搜索、列表选择、检查器控件、JSON 确认和 Escape 关闭检查器；关闭后 VoiceOver 焦点回到操作条检查器按钮。
4. 用 VoiceOver 读取观察列表总数、每行名称/代码/价格/方向/stale 原因、分时与 B/S 说明、刷新状态、错误、提醒横幅和三个 destructive confirmation。
5. 在“数据”区检查 provider、最近刷新、缓存分钟数、手动刷新、复制数据库路径和清空缓存；清空后观察列表和提醒设置必须保留。

## 自动检查范围

测试代码覆盖自由窗口几何、inspector 宽度策略、浅色 token、工具注册、输入限制、ASCII 默认静态/静态导出/固定比例/动画生命周期/窗口可见性/Metal 路径/画布变换，股票看盘的领域校验、provider 解析与 fallback、数据库 schema/迁移、刷新、容错缓存、JSON、提醒和关键布局计算，以及 PodPin 的类型化 route push/pop、导入草稿、热重入、文件夹可见行扁平化、下载进度合并、数据库、资料库规则、四来源 fixture、下载状态机、在线回退、播放、听过区间、队列、惰性启动和退出清理。UI 测试还会在隔离组合根强制 Reduce Motion，并在 PodPin push/pop 的淡变重叠期间采样新旧路由实际 frame，自动检查没有横向位移。Release package benchmark 自动检查可确定性的绝对门槛，Release UI 计划另检查工具暖切换、PodPin 热重入、inspector/路由首变化与本地 fixture 到 `AVPlayer` 播放状态的绝对 P95；视觉构图、真实公开端点、实际输入设备、物理声音输出、系统媒体键、系统授权面板、辅助技术和完整端到端时序仍需要人工或固定机 Instruments 检查。只有运行对应命令后的结果才能作为通过证据。

## 当前未验证

- 上述股票看盘人工路线，包括最小/默认/宽屏/纵向窗口、宽/窄行情行切换、长列表、错误/stale、真实搜索与 provider fallback、JSON、提醒声音和数据诊断。
- 股票看盘视图取消后的真实在途网络请求与离屏零请求端到端验证。
- 实体触控板捏合手感。
- VoiceOver、Voice Control、Switch Control 和 Full Keyboard Access 的端到端任务。
- ASCII 和股票看盘错误横幅在最小、默认、宽屏和纵向窗口的视觉状态。
- PodPin 内容区、次级路由和队列 inspector 在最小、默认、宽屏和纵向窗口的完整人工视觉构图，以及浏览器 Profile 的真实 Keychain 授权、真实抖音下载、系统媒体键和输出设备切换。
- 自动化已覆盖测试环境中的 PodPin Reduce Motion push/pop 横向位移；真实系统偏好下的淡变时长、录屏构图，以及 VoiceOver、Voice Control、Switch Control 和 Full Keyboard Access 联合 smoke 仍需人工验收。
- 检查器关闭后的焦点恢复保持人工验收：当前 macOS XCTest 的 `XCUIElement` 不暴露可查询的键盘焦点状态；自动化只验证关闭后发起控件重新存在且可立即操作。
- 独立 PodPin 与 OneBox 同时访问旧资料库；该组合不在支持范围内。
- 窗口截图自动化受系统权限限制时，无法据此声称视觉构图已验收。
- `./scripts/benchmark-ascii.sh`、`./scripts/benchmark-stock-watch.sh` 与 `./scripts/benchmark-podpin.sh` 的本机 Release 基准，除非本次交付另附实际运行结果。
