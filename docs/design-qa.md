# UI 验收

强制视觉契约见 [设计规范](design.md)。本文件只记录可复现步骤和当前未验证项；截图不进入版本库。以下人工路线是交付前待执行清单，不表示本次文档更新已经完成这些验证。

## 运行

1. 在 Apple Silicon 本机运行 `./scripts/check.sh`。
2. 从 Xcode 运行 `OneBox`，或启动 Debug 产物：
   - 默认窗口：`.build/DerivedData/Build/Products/Debug/OneBox.app/Contents/MacOS/OneBox --ui-default`
   - 最小窗口：`.build/DerivedData/Build/Products/Debug/OneBox.app/Contents/MacOS/OneBox --ui-minimum`
3. 需要性能或内存证据时按变化范围另运行：
   - ASCII：`./scripts/benchmark-ascii.sh`
   - 股票看盘：`./scripts/benchmark-stock-watch.sh`

`--ui-*` 参数只存在于 Debug 构建。`--ui-dark` 可用于检查结构，但深色不是产品外观或验收目标。

## 通用人工路线

- 默认和最小窗口：检查固定比例、侧栏折叠、四个工具切换，以及无截断、重叠、意外换行或水平滚动。
- 键盘：只用键盘走完当前工具主任务；确认快捷键不抢占文本输入，Escape 关闭当前层，并把焦点恢复到发起控件。
- 辅助功能：用 VoiceOver 读出控件名称、状态、当前值、错误和不可逆影响；再检查 Voice Control、Switch Control、Full Keyboard Access、减少动态效果及不依赖颜色的状态表达。

## ASCII 工坊人工路线

- 检查默认品牌素材、导入、比例、配色、参数、播放、导出、拖放、平移、缩放和预览/导出构图一致。
- 持续拖到物理屏幕边缘后，内容仍可继续平移；松开或切走窗口后指针恢复正常。
- 画布聚焦时检查方向键、`+`/`-`、`0`、空格和 Escape；字符输入中的空格不触发播放。
- 检查名称、状态、手势替代操作、减少动态效果和关闭检查器后的焦点恢复。

## 股票看盘人工路线

### 窗口、长列表和颜色

1. 在默认和最小窗口选择“股票看盘”，分别展开和折叠宿主侧栏。检查 loading、成功内容、空列表和启动失败页面不会重复产品品牌或工具标题。
2. 在内容宽度 699pt 和 700pt 两侧调整窗口：窄布局用右侧 320–360pt 覆盖检查器，宽布局用 248pt dock；行情表不得被压出水平滚动。检查器默认展开，关闭后行情表恢复空间。
3. 用受控有效 JSON 建立足以滚动的长列表，连续滚动、选择、拖动排序、用检查器上下移和移除；确认行高、稳定列、选中底色和操作反馈不跳动，重进工具后顺序保持。
4. 对 A股/港股检查红涨绿跌，对美股检查绿涨红跌，对持平检查中性色。每个方向必须同时有正负号、箭头和 VoiceOver 文本。A股收盘复盘的 B/S 标记必须保持在图内并可读出含义。

### 错误、stale 和刷新

1. 完成一次成功刷新后切换到其他工具再返回；先恢复的缓存应明确显示“本地缓存”或 stale，不能伪装为实时数据。
2. 在受控断网下检查全量失败、恢复网络后的重试，以及部分 provider 失败；已成功缓存保留，工具条或对应行状态说明来源问题，界面不承诺恢复时间。
3. 用测试用用户目录或失败数据库 adapter 分别触发启动、观察列表写入、提醒写入和缓存清理错误；检查默认/最小窗口中的错误文案、优先级、重试或关闭提示。错误不显示搜索词、自选内容或完整请求，数据库路径只在专门诊断控件中展示。
4. 在工具刷新中切换到其他工具，确认视图 task 取消后没有新的搜索或行情请求，待保存提醒已 flush，数据库可再次打开。窗口只被遮挡、失焦或最小化不属于此路线的停机断言。

### 搜索和 JSON

1. 按 Command-N 打开添加标的，确认搜索框获得焦点；分别用名称和代码搜索 A股、港股、美股，检查同代码不同 `SymbolNamespace` 的显示。
2. 用 Return 提交，覆盖 loading、取消、空结果、网络失败、重试、重复添加和成功添加；Escape 关闭并确认焦点回到合理位置。
3. 打开 JSON 整体替换，检查“填入当前列表”和复制结果。分别提交空文本、非法 JSON、无效 namespace/代码/名称和重复标的；失败不得应用部分列表。
4. 对有效替换先取消 destructive confirmation，再确认一次；检查顺序按 JSON 保留，已移除标的的目标价和缓存消失。移除标的和清空缓存也必须分别确认且文案说明不可撤销范围。

### 提醒和数据诊断

1. 切换百分比与目标价依据，检查总开关、0.5%–15% 阈值、按现价生成目标、单标的上涨/下跌目标，以及无现价时的禁用或错误反馈。
2. 分别预览上涨和下跌提醒，检查牛/熊声音独立开关、方向图标和文字、按市场变化的颜色、6 秒自动消失，以及鼠标悬停或键盘焦点期间暂停。减少动态效果时只允许淡入淡出。
3. 只用键盘完成 Command-N、搜索、列表选择、检查器控件、JSON 确认和 Escape 关闭检查器；关闭后 VoiceOver 焦点回到操作条检查器按钮。
4. 用 VoiceOver 读取观察列表总数、每行名称/代码/价格/方向/stale 原因、分时与 B/S 说明、刷新状态、错误、提醒横幅和三个 destructive confirmation。
5. 在“数据”区检查 provider、最近刷新、缓存分钟数、手动刷新、复制数据库路径和清空缓存；清空后观察列表和提醒设置必须保留。

## 自动检查范围

测试代码覆盖窗口几何、浅色 token、工具注册、输入限制、ASCII 静态导出/固定比例/动画生命周期/Metal 路径/画布变换，以及股票看盘的领域校验、provider 解析与 fallback、数据库 schema/迁移、刷新、缓存、JSON、提醒和关键布局计算。视觉构图、真实公开端点、实际输入设备、声音和辅助技术仍需要人工检查；只有运行对应命令后的结果才能作为通过证据。
