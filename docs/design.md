# 设计规范

OneBox 将 BoardUI 的实际组件、主题和动效移植为 SwiftUI 原生界面：白色页面、浮动浅灰侧栏、蓝色操作、Inter 字体和 24pt 圆角面板。用户已明确选择保留 SwiftUI，并以 BoardUI 为当前视觉与动效依据。生产外观固定为浅色；宿主和三个工具共享 DesignSystem。来源、组件映射和原生边界见 [BoardUI 原生适配](boardui-native.md)。

## 宿主

- 默认窗口为 1048×648pt；最小高度为 556pt，最小宽度沿用原默认比例计算。窗口不锁定宽高比，用户可以独立加宽或加高。
- 侧栏是外部留白 12pt 的浮动面板：展开宽 260pt，窄窗口为 212pt，并在窗口接近默认宽度时连续增至 260pt，折叠为 60pt 图标栏。面板圆角 24pt，内部留白 12pt。主内容左右和底部内边距为 24pt，顶部为 8pt；标题组再留 8pt 顶边距，与工具工作区间距 16pt。
- 侧边栏顶部显示一次 `24pt 标识 + OneBox`。内容区由宿主显示当前工具的名称和一句功能说明，来自 registration 的 `displayName` 与 `summary`；工具页面保留任务标题和上下文名称。
- 一级导航使用 20pt SF Symbol 和文字，行高 36pt。选中行使用蓝色纵向渐变、顶部内高光及白色文字/图标；未选中行使用灰色文字，悬停反馈采用中性表面。浮动侧栏使用 BoardUI 的轮廓与环境阴影。
- 导航按下立即反馈和切换选中状态，不等待新工具内容挂载；一级切换不使用位移或弹跳。
- 侧栏展开时品牌与折叠按钮同排；折叠后保留展开按钮、品牌图标、三个工具和调试入口。折叠/展开使用 300ms `(0.4, 0, 0.2, 1)` 曲线。顶部保留稳定占位，导航图标的横轴和行基线不变；品牌、开关与日志按钮保留同一控件身份。标签先按原始单行排版，再裁切淡出，避免挤压换行；减少动态效果时立即切换。
- 侧栏底部提供独立的“调试日志”入口及“记录中”状态，不占用工具导航项；切换主窗口底部的日志区域，保留当前工具内容与操作空间。
- 不实现全局搜索、命令面板、第二套导航或常驻快捷键说明。
- 工具说明解释用途；行内元数据服务当前任务。相同页面不重复当前目的地操作，错误与空态提供可执行的下一步。

## 字体与布局

正文与标题使用随 `OneBoxDesignSystem` 打包的 Inter 4.1 variable 字体，在当前进程中一次性注册；中文字符使用系统字体回退。等宽诊断与 SF Symbols 保留系统字体。统一字体角色为：

| 角色 | 规格 |
| --- | --- |
| Page title | 24pt / Medium |
| Sidebar title | 18pt / Medium |
| Metric | 20pt / Medium |
| Artwork symbol | 48pt / Light，仅用于大封面缺失时的占位符 |
| Section title | 16pt / Medium |
| Body / Control | 14pt / Regular 或 Medium |
| Compact | 13pt / Regular |
| Metadata | 12pt / Regular |
| Diagnostic | 12pt / Regular / Monospaced，用于完整原始错误 |

- 可见文字不得小于 12pt；需要列对齐的数字使用 `.monospacedDigit()`。
- 布局间距使用 4、8、12、16、24、32 和 48pt。侧栏外部与内部各留白 12pt，品牌和导航内容在面板内对齐；导航文字在图标之后对齐。工作区面板圆角为 24pt；表格封面等小元素保留 12pt 圆角。
- 同层内容共享左右边线；使用 frame、Grid、alignment guide 或基线对齐。页面布局不依靠负 padding、任意位移或透明字符补位；开关圆点等控件内部状态可以使用明确的位移。
- 工具内功能图标使用 SF Symbols。共享图标按钮为 32×32pt，状态图标可以使用 24pt 容器；纯图标按钮提供辅助功能名称与悬停提示。
- 辅助内容统一通过 DesignSystem 的 `.toolInspector` modifier 使用原生 SwiftUI trailing inspector：`.standard` 固定 248pt，`.queue` 使用 min 280 / ideal 320 / max 360pt。原生尾随列和 separator 推挤主内容；检查器默认收起并在首次明确打开时才安装，避免工具首帧为不可见辅助内容付费，安装后保留以支持立即反向。首次先挂载关闭的原生容器，再将原生呈现与占位宽度放入同一 300ms 侧栏事务；首次延迟只读取当前请求，后续开关立即同步原生状态；忽略不改变原生目标的确认回写，避免迟到重开。主区与分隔线之间留 12pt，关闭时恢复完整宽度；标题栏高 36pt，与工具栏对齐。检查器采用统一白色表面、标题栏、分隔线、滚动区与关闭按钮，支持 Escape、辅助功能 escape 及发起控件的焦点恢复；业务内容按 `InspectorSection` 分组。

### 共享控件

- `ToolActionButtonStyle` 提供 primary、secondary、quiet 三种层级。常规最小高 36pt、圆角 10pt；compact 最小高 32pt、圆角 8pt。主操作使用蓝色纵向渐变、顶部细高光与轻接触阴影；次操作为白色描边，quiet 使用轻量悬停底。危险次操作与 quiet 操作为红色文字。
- 按钮按下缩放至 0.98，按下 220ms、回弹 420ms，曲线为 `(0.4, 0, 0.2, 1)`；色彩反馈 150ms。此参数来自已安装的 BoardUI `button.tsx` 和 CSS 变量，优先于旧技能摘要中“按下不缩放”的概括。减少动态效果时关闭缩放和动画。
- `ToolIconButtonStyle` 为 32pt 紧凑触达区域，保留明确的禁用、悬停与激活状态。原生菜单使用同样的图标及文字角色；菜单自身仍由 macOS 呈现。
- `ToolSwitchStyle` 使用 42×24pt 轨道、18pt 白色圆点与 7.5pt 中心压印。开启为蓝色渐变、关闭为中性轨道，选中转换为 200ms；辅助功能提供原生 Toggle 语义。
- `ToolSegmentedPicker` 使用 4pt 内缩轨道和白色移动选中层，单段最小高 28pt、整体最小高 36pt；方向键切换值并转移焦点，选中移动使用 200ms 曲线。
- `ToolTextField` 保留原生文本编辑和外部 FocusState，绘制随聚焦变化的占位文字。字段为 `#EBEBEB` 底、10pt 圆角、36pt 最小高度；悬停/聚焦使用 2pt 中性内边框。PodPin 多行 `TextEditor` 保留原生编辑并采用相同表面，替代此前的外发光焦点环。
- `ToolSlider` 在 32pt 高区域内呈现 6pt 轨道、20pt 圆点与 8pt 中心色片。保留拖动、方向键、Page Up/Down、Home/End 与辅助功能调整；通过原有 `Binding` 和编辑开始/结束回调连接业务。ASCII 参数、股票提醒阈值及 PodPin 的播放/音量均使用它。
- 选择、提示和布局通过 `DesignMotion` 统一时序。完整参数、BoardUI 来源与原生菜单/sheet 的边界见 [适配说明](boardui-native.md)。

交互层级遵循同一规则：宿主一级工具选择立即切换；工具内次级页面从 trailing 推入、返回时反向；辅助信息进入 trailing inspector；只有具有提交/取消边界的任务使用 sheet。Escape 依次关闭系统 sheet 或 popover、trailing inspector、当前工具的 drill-in 页面，根页面不响应。状态更新、下载和播放进度不得继承页面或检查器的呈现动画。

## 调试日志

- 日志内嵌在主窗口工作区底部，使用原生分隔线调整高度；上方工具继续挂载并保持可操作，便于一边重现一边查看。侧栏入口与 `⇧⌘L` 切换展开状态；侧栏展开时选择当前模块，快捷键保留已有筛选。工具错误提示中的入口始终展开并选择对应模块，关闭按钮只收起日志。
- 顶部为标题与调试开关；其下以分段器筛选全部/三个工具，并提供带搜索图标的错误/操作/时间搜索、复制筛选结果和清空。列表按发生时间由新到旧，详情使用可选中的等宽文字。原始错误默认自动换行，可切换为保留原行宽的横向滚动；该显示开关不改变复制内容。
- 列表显示本地时分秒，详情和复制内容包含毫秒及时区；单条复制提供 `⇧⌘C`，完成后显示“已复制”。底栏表达是否采集、筛选数量和较早记录淘汰情况。
- 未开启时引导开启后重现；无匹配记录时提示调整筛选。关闭采集保留已收集内容，清空仅移除本次内存日志，不影响工具业务数据。

## 工具内容

工具拥有内容和领域操作，不改变宿主导航、全局配色或字体尺度。上下文快捷键只在工具可见且焦点正确时生效。

ASCII 工坊遵守以下布局和交互：

- 内容由紧凑操作条、单层画布和按需展开的 248pt 右侧检查器组成；检查器默认收起，可以从操作条打开、从操作条或自身关闭，并支持 Escape 和辅助功能 escape。
- 单行操作条无外层卡片并与画布左右对齐。导入、画布、动画和输出按任务顺序分组；同组间距为 8pt、组间距为 16pt。配色和动画使用宽度稳定的单层菜单，播放与参数使用固定 32pt 图标位，唯一主操作“导出 PNG”使用共享渐变按钮并位于右侧。
- 操作条不足 680pt 时，比例、配色和动画选择合并到“画布”菜单；打开、播放、参数和完整的“导出 PNG”仍保留在操作条，不压缩主操作文字。
- 画布只提供 1:1、16:9 和 9:16，并始终完整适配工作区；检查器不改变输出几何。画布使用浅灰衬底和白色底部控制条，显示导出尺寸并提供缩小、重置比例与放大。
- 透明画布使用 `surface` 与 `surfaceElevated` 棋盘格，棋盘格不进入导出。
- 拖动使用捕获后的相对指针位移平移，不受物理屏幕边缘限制；滚轮和捏合以指针位置缩放；双击或“重置视图”恢复默认构图。
- 画布聚焦时，方向键平移，`+`/`-` 缩放，`0` 重置，空格播放或暂停。文本输入中的空格不得触发播放。
- 新会话无论是否开启减少动态效果都默认静态；已有明确动画选择继续保留。只有用户显式选择动画并播放、且工具与窗口可见时才持续绘制；离屏、最小化或完全遮挡时暂停。

### PodPin

- 内容区使用一行紧凑工具栏、单层资料库列表和底部播放条，不复制独立 PodPin 的
  `NavigationSplitView`、窗口标题、品牌标识、雾绿色配色、材料卡片或圆角字体。
- 工具栏按任务顺序提供集合/文件夹选择与管理、导入和正在播放。当前上下文必须
  以文字或控件状态表达，不能只用颜色；图标操作保留辅助功能名称和键盘入口。
- 集合选择采用文件夹图标、文字标题和下拉箭头；资料库置于白色描边表面，音频行采用 40pt 封面、最多两行标题和一行作者/来源/时长。悬停和选中分别反馈，表头与图标列对齐，行间使用完整分隔线；下载状态保持可见，排队操作集中于行菜单和右键菜单。
- 播放器可用内容宽度达到 600pt 时采用封面与播放信息并排布局，否则使用纵向布局；队列展开后内容宽度不得超过实际剩余空间。宽松布局标题使用 Metric，紧凑低窗口使用 Section title；播放键采用共享蓝色矩形主按钮，快退/播放/快进保持居中，速率独立放在左侧。
- 音量与输出由扬声器按钮打开原生 popover，原生输出设备选择器仅在面板打开时构建。Escape 先关闭面板并保留当前播放页面；播放进度仍只更新局部时间轴视图。
- 集合选择在一块面板内先列出最近导入、最近播放和已下载，再显示可展开的文件夹树；选择后立即关闭并恢复按钮焦点。导入、创建、移动位置均复用该树，菜单只提供“移动到…”入口，不递归飞出子菜单。
- 资料库采用 BoardUI table 的表头、12pt 单元格横向留白和约 64pt 内容行，较长标题按内容增高；展示封面、作者/来源、时长、存储状态与真实听过区间。
  hover 操作不能成为唯一入口；相同命令也必须通过焦点或上下文菜单到达。
- 播放条常驻于 PodPin 内容底部，提供当前项、播放/暂停、15/30 秒跳转、进度、速率和
  待播队列入口。播放条使用独立白色表面；没有当前项时只保留导入引导、速率和队列，导入页将该引导改为静态说明。
- 资料库是根页面。导入和正在播放组成类型化 push/pop 路径：push 从 trailing 进入，pop 完全反向，重复当前目的地不重复入栈；导入成功或切换集合回到根页面。从导入进入正在播放再返回时，URL、目标文件夹和分段选择草稿必须保留。
- 路由使用 300ms `(0.32, 0.72, 0, 1)` 曲线且不弹跳；减少动态效果时改为不超过 100ms 的淡变，不发生横向位移。返回按钮使用箭头并说明真实目的地，不使用关闭叉号代替返回。
- 待播队列始终作为 `.queue` 原生右侧检查器推挤正在播放页，不因窗口宽度改为覆盖、替换播放器或拼成另一套布局。PodPin 不提供设置页；播放速率直接出现在紧凑播放条和正在播放页，没有当前音频时也可以选择并持久化。
- 窄窗口工具栏保留“导入”文字；正在播放可退化为图标，并保留完整辅助功能名称。导入页隐藏重复的导入入口，当前正在播放入口禁用并表明已打开。队列元数据显示作者（缺少时为来源）与时长，清空队列采用带确认的 quiet 危险操作。
- 导入页面正文最大宽度为 680pt，内边距 24pt，多行输入最小高 112pt；识别反馈、目标文件夹与提交动作按任务顺序排列。
- 默认、最小、横向加宽和纵向加高窗口都不得依赖水平滚动、负 padding、任意 offset 或隐藏核心操作；检查器打开时也不得覆盖主内容。

### 股票看盘

股票看盘保留 OneBox 宿主、侧栏和浅色 token，不迁入独立应用标题栏、品牌名、浮窗、菜单栏或第二套设置壳。其 OneBox UI 例外只服务高密度行情与市场语义：

- 内容由单行操作条、白色观察列表与选中标的分时大图组成；高度不足时保留观察列表和清晰的行内走势。左侧唯一主操作为“添加标的”，使用共享渐变按钮；JSON 操作进入“列表”菜单。刷新状态、手动刷新和检查器开关位于右侧，图标提示可读取完整状态。
- 行情宽行按名称/代码/交易所、分时、最新价/涨跌幅形成稳定列；空间不足时降级为名称、代码/状态、价格和涨跌方向，隐藏分时且不出现水平滚动。任意数量通过垂直滚动承载，不为长列表增加分页或独立窗口。数字使用等宽数字。
- 检查器默认收起，打开后连续排列“所选标的、价格提醒、数据”而不是分成多套导航；始终以原生右侧 248pt trailing inspector 出现，窄窗口仅降级行情行，绝不覆盖内容。
- 添加标的和 JSON 整体替换使用任务型 sheet。替换观察列表、移除标的和清空缓存必须在操作前显示明确影响及 destructive confirmation。
- `warning` 与 `warningSurface` 表达 stale 及需要注意的行情状态；存储失败、搜索/JSON 失败和不可逆警告使用 `negative` 与 `negativeSurface`。错误横幅完整换行并提供重试或日志入口；状态同时提供明文、图标或符号。
- 行情源成功返回较早交易日的数据时，行内使用中性时钟和“最近行情 · YYYY-MM-DD”，检查器显示“最近交易日价格”；该状态不显示错误横幅，也不作为当前价格触发提醒。
- A股和港股使用红涨绿跌；美股使用绿涨红跌；持平使用 `textPrimary`。此处红色来自 `negative` token 只是在承担红色领域角色，不代表 A股/港股上涨是错误状态。
- 分时价格线使用统一蓝色，避免逐分钟红绿切换干扰读图；涨跌数字和提醒继续遵循市场颜色约定。选中标的大图使用局部深色语义配色、价格刻度、交易时段轴、昨收虚线和悬停分钟读数；不改变宿主浅色外观。低价标的按实际振幅与相对价格留白，避免固定绝对留白压平走势。A股收盘复盘的 `B` 固定为绿色、`S` 固定为红色，并保留字母标签和辅助功能说明，不能只靠颜色解释。
- 当前首选行情源仅提供分钟采样价，界面标为分时，不伪造蜡烛实体或分钟内高低价。午休按市场交易时段折叠，早盘曲线不拉满全天；悬停读数保留数据的原始时间。
- 上涨/下跌提醒的领域色按标的市场规则变化，同时显示方向图标、标题和数值。牛熊声音只是补充反馈，不替代可见或可读状态。
- 提醒横幅悬停或键盘聚焦时暂停自动消失；减少动态效果开启时只使用淡入淡出。关闭检查器后，辅助功能焦点恢复到操作条的检查器按钮。

交付 UI 变化前，按 [UI 验收](design-qa.md)完成检查。

## 实现参考

实现沿用以下一手资料中的原生交互和布局原则：

- [Apple：Optimize SwiftUI performance with Instruments](https://developer.apple.com/videos/play/wwdc2025/306/)：用更新耗时与因果关系定位热点，将辅助控件的准备和高频状态更新限制在实际使用的视图。
- [Things：Hello, X!](https://culturedcode.com/things/blog/2017/11/hello-x/)：减少装饰和常驻按钮，让内容成为视觉主体。OneBox 将时长放回音频元数据，并减少工具栏与集合选择的外框。
- [Raycast：How the Raycast API and extensions work](https://www.raycast.com/blog/how-raycast-api-extensions-work)：不同功能遵循同一套原生交互。借鉴一致的功能入口与更新边界，不引入其扩展运行时或改换 OneBox 的 Swift 技术栈。
- [Apple：Inspectors in SwiftUI](https://developer.apple.com/videos/play/wwdc2023/10161/)：使用原生 trailing inspector 与清晰的表单分组；此模式适配当前 macOS 15 最低版本。
- [Apple：Toggles](https://developer.apple.com/design/human-interface-guidelines/toggles/)：主开关强调一组功能，从属设置采用紧凑控件，利用对齐表达依赖关系。
- [Apple：Build a SwiftUI app with the new design](https://developer.apple.com/videos/play/wwdc2025/323/)：使用控件尺寸维持高密度 Mac 布局；macOS 26 的 Liquid Glass 和新工具栏 API 需要 availability 分支，不作为 macOS 15 的无条件依赖。
