# 设计规范

OneBox 使用紧凑的原生 macOS 界面。生产外观固定为浅色；宿主和工具共享 DesignSystem，不在页面内另建字体、颜色或间距体系。

## 宿主

- 默认窗口为 1048×648pt，并锁定该比例；最小高度为 556pt，最小宽度由同一比例计算。
- 侧边栏固定为 224pt；主内容左右和底部内边距为 24pt，顶部为 8pt。
- 侧边栏顶部只显示一次 `24pt 标识 + OneBox`；内容区不重复品牌名或工具标题。
- 一级导航使用纯文字和单层中性选中底，不使用图标、描边、强调色竖线、阴影或全高分隔线。
- 侧栏只有一个折叠按钮：展开时位于侧栏右上方，折叠后位于主区左上方。
- 不实现全局搜索、命令面板、第二套导航或常驻快捷键说明。
- 删除不影响理解、数据含义或风险判断的副标题、提示语和重复元数据。

## 浅色配色

宿主颜色必须使用 DesignSystem 语义 token。ASCII 工坊的领域配色只作用于输出画布；股票看盘的涨跌领域配色只作用于行情、分时和提醒方向。两者都不得改变宿主导航或全局 tint。

| Token | Hex | 用途 |
| --- | --- | --- |
| `background` | `#FBFBFA` | 主内容背景 |
| `sidebar` | `#F0F0EE` | 侧边栏背景 |
| `surface` | `#FFFFFF` | 控件和独立表面 |
| `surfaceElevated` | `#EEEEEC` | 悬停表面和透明棋盘格 |
| `selection` | `#E4E4E2` | 导航选中底色 |
| `border` | `#D8D8D5` | 组件内部边框 |
| `textPrimary` | `#1B1C1E` | 主文字 |
| `textSecondary` | `#66676A` | 次级文字和功能图标 |
| `accent` | `#BC4535` | 主操作和焦点 |
| `positive` | `#087A4B` | 成功语义和股票看盘的绿色领域角色 |
| `negative` | `#B42318` | 错误语义和股票看盘的红色领域角色 |
| `warning` | `#8F6400` | stale、provider 或需要注意的状态 |
| `info` | `#1C587B` | 信息语义；当前保留给明确的信息状态 |
| `infoSurface` | `#E8F3F9` | 信息语义表面；当前保留给与 `info` 配对的状态 |
| `brandMarkHost` | `#3569CE` | 侧栏标识外盒和五官 |
| `brandMarkCore` | `#FFF1D6` | 侧栏标识内核 |
| `brandGradientStart` | `#3B6FD8` | ASCII OneBox 配色起点 |
| `brandGradientMiddle` | `#8A5CBF` | ASCII OneBox 配色中点 |
| `brandGradientEnd` | `#BC4535` | ASCII OneBox 配色终点 |

- 应用根视图使用 `accent` 作为 tint，不出现系统蓝色控件。
- 常驻颜色不得通过透明度临时派生；新增颜色先定义用途明确的语义 token。
- 状态不能只依赖颜色表达。
- 配色变更必须同步更新本表、`LightPaletteHex`、`LightPaletteTests` 和 UI 验收。

## 字体与布局

统一使用 SF Pro 和 DesignSystem 字体角色：

| 角色 | 规格 |
| --- | --- |
| Sidebar title | 20pt / Semibold |
| Metric | 20pt / Semibold |
| Section title | 14pt / Semibold |
| Body / Control | 13pt / Regular 或 Medium |
| Metadata | 12pt / Regular |

- 可见文字不得小于 12pt；需要列对齐的数字使用 `.monospacedDigit()`。
- 当前间距使用 4、8、12、16 和 24pt。侧栏外边距为 12pt，品牌标识和导航文字从 20pt 左轴开始。
- 同层内容共享左右边线；使用 frame、Grid、alignment guide 或基线对齐，不用负 padding、任意 `offset` 或透明字符补位。
- 工具内功能图标使用 SF Symbols，常规图标采用 16×16pt 光学框和 24×24pt 容器；纯图标按钮必须有辅助功能名称。
- 所有参数和设置检查器统一使用 `ToolInspectorPanel`：固定 248pt、右侧推拉而非覆盖主内容，拥有一个标题栏和一个滚动区，并提供关闭按钮、Escape、辅助功能 escape 及发起控件的焦点恢复。

## 工具内容

工具拥有内容和领域操作，不改变宿主导航、全局配色或字体尺度。上下文快捷键只在工具可见且焦点正确时生效。

ASCII 工坊遵守以下布局和交互：

- 内容由紧凑操作条、单层画布和默认展开的 248pt 右侧检查器组成；检查器可以从操作条或自身关闭，并支持 Escape 和辅助功能 escape。
- 单行操作条无外层卡片并与画布左右对齐。导入、画布、动画和输出按任务顺序分组；同组间距为 8pt、组间距为 16pt。配色和动画使用宽度稳定的单层菜单，播放与参数使用固定 32pt 图标位，唯一实心主操作“导出”位于右侧。
- 画布只提供 1:1、16:9 和 9:16，并始终完整适配工作区；检查器不改变输出几何。
- 透明画布使用 `surface` 与 `surfaceElevated` 棋盘格，棋盘格不进入导出。
- 拖动使用捕获后的相对指针位移平移，不受物理屏幕边缘限制；滚轮和捏合以指针位置缩放；双击或“重置视图”恢复默认构图。
- 画布聚焦时，方向键平移，`+`/`-` 缩放，`0` 重置，空格播放或暂停。文本输入中的空格不得触发播放。
- 减少动态效果开启时默认静态，用户显式播放后才能启动动画。

### PodPin

- 内容区使用一行紧凑工具栏、单层资料库列表和底部播放条，不复制独立 PodPin 的
  `NavigationSplitView`、窗口标题、品牌标识、雾绿色配色、材料卡片或圆角字体。
- 工具栏按任务顺序提供集合/文件夹选择与管理、导入、正在播放和设置。当前上下文必须
  以文字或控件状态表达，不能只用颜色；图标操作保留辅助功能名称和键盘入口。
- 集合选择在一块面板内先列出最近导入、最近播放和已下载，再显示可展开的文件夹树；选择后立即关闭并恢复按钮焦点。导入、创建、移动位置均复用该树，菜单只提供“移动到…”入口，不递归飞出子菜单。
- 资料库行在 56pt 基线上显示封面、标题、作者/来源、时长、存储状态与真实听过区间。
  hover 操作不能成为唯一入口；相同命令也必须通过焦点或上下文菜单到达。
- 播放条常驻于 PodPin 内容底部，提供当前项、播放/暂停、15/30 秒跳转、进度、速率和
  待播队列入口。没有当前项时显示可执行的导入引导，不显示无行为的 transcript 控件。
- 导入和正在播放在同一工具内容区切换；设置默认关闭，打开时作为右侧 248pt 检查器推挤当前内容，关闭后回到原页面。正在播放可以使用封面作为有限的领域信息，但仍使用 OneBox 语义 token、字体和控件，不建立另一套全屏配色。
- 窄窗口工具栏保留“导入”文字；正在播放和设置可退化为图标，但必须保留完整辅助功能名称。
- 默认侧栏展开时按约 776×616pt 验收，最小窗口按约 627×524pt 验收；两种尺寸都不得
  依赖水平滚动、负 padding、任意 offset 或隐藏核心操作。

### 股票看盘

股票看盘保留 OneBox 宿主、侧栏和浅色 token，不迁入独立应用标题栏、品牌名、浮窗、菜单栏或第二套设置壳。其 OneBox UI 例外只服务高密度行情与市场语义：

- 内容由 32pt 单行操作条和单一行情表面组成，不给操作条增加外层卡片。左侧唯一实心主操作为“添加标的”，JSON 操作收进省略号菜单；刷新状态、手动刷新和检查器开关位于右侧。
- 行情宽行按名称/代码/交易所、分时、最新价/涨跌幅形成稳定列；空间不足时降级为名称、代码/状态、价格和涨跌方向，隐藏分时且不出现水平滚动。任意数量通过垂直滚动承载，不为长列表增加分页或独立窗口。数字使用等宽数字。
- 检查器默认展开，连续排列“所选标的、价格提醒、数据”而不是分成多套导航；始终以右侧 248pt 推拉布局出现，窄窗口仅降级行情行，绝不覆盖内容。
- 添加标的和 JSON 整体替换使用任务型 sheet。替换观察列表、移除标的和清空缓存必须在操作前显示明确影响及 destructive confirmation。
- `warning` 表达 stale，以及行情源或存储横幅中需要注意的状态；工具条的存储失败、搜索/JSON 失败和不可逆警告使用 `negative`。状态必须同时提供明文、图标或符号，不能只依赖颜色。
- A股和港股使用红涨绿跌；美股使用绿涨红跌；持平使用 `textPrimary`。此处红色来自 `negative` token 只是在承担红色领域角色，不代表 A股/港股上涨是错误状态。
- 分时线的每个方向段遵循所属市场的涨跌颜色，昨收水线使用中性 `border`。A股收盘复盘的 `B` 固定为绿色、`S` 固定为红色，并保留字母标签和辅助功能说明，不能只靠颜色解释。
- 上涨/下跌提醒的领域色按标的市场规则变化，同时显示方向图标、标题和数值。牛熊声音只是补充反馈，不替代可见或可读状态。
- 提醒横幅悬停或键盘聚焦时暂停自动消失；减少动态效果开启时只使用淡入淡出。关闭检查器后，辅助功能焦点恢复到操作条的检查器按钮。

交付 UI 变化前，按 [UI 验收](design-qa.md)完成检查。
