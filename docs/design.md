# 设计规范

本规范是 OneBox 的强制 UI 契约。宿主和所有工具模块都必须遵守；局部页面不得自行覆盖全局字体、颜色、间距、图标或对齐规则。

本规范是自包含的实现输入。参考产品、模板、历史截图或生成代码都不能替代本文约束；需要改变视觉方向时直接更新本规范和对应验收基线，不在仓库并列维护参考产品规范副本。

## 不可回退的设计决定

以下决定来自已经完成的界面纠正，不是建议项。除非用户明确重新开启对应设计决策，否则模板迁移、重构、生成代码或参考其他产品均不得改变：

- 默认且正式验收的外观是浅色；深色只保留占位，不得反向影响浅色的颜色或几何结构。
- 不实现全局搜索。用户明确知道 OneBox 中的固定工具，侧边栏直接切换就是完整入口。
- `OneBox` 只在侧边栏左上方显示一次，不添加品牌菜单、下拉箭头或内容区重复品牌名。
- 默认删除解释型小字；不得用副标题、提示语和重复元数据填充空白。
- 一级导航使用纯文字。侧栏品牌行允许一个 24pt OneBox“套盒”品牌标识；侧栏折叠按钮仍是唯一常驻功能图标，工具内只使用与真实操作对应的 SF Symbols。
- 宿主分区不使用全高线条、内阴影或渐变边缘；选中项不使用 `border-left`、强调色竖线、描边、阴影或多层 highlight。
- 默认窗口比例固定为 1048:648，侧边栏固定为 224pt；品牌名与导航文字共享 20pt 左轴，既定纵向间距不得凭感觉微调。
- 浅色 token 是锁定值。唯一宿主装饰性颜色例外是已批准的 OneBox“套盒”品牌系统；侧栏使用透明底 24pt optical mark，`OneBox` 字标整体保持主文字色，宿主不得再为标识增加发光、阴影或动画。
- 折叠行为采用单一标题栏按钮：展开时位于侧边栏右上方，折叠后位于主区左上方；不得增加第二个折叠入口或常驻说明。

## 设计方向

- 采用受 Raycast 启发的紧凑桌面工具风格，但保持原生 macOS 结构和 SwiftUI 行为，不复制其营销页面。
- 使用中性表面、必要的局部细分隔线和单一珊瑚红强调色；不使用大面积渐变、霓虹背景或装饰性色块堆叠。唯一宿主例外是 OneBox“套盒”品牌标识的固定外盒与内核配色；ASCII 工坊的七套领域配色只作用于输出画布。
- 信息直接进入任务，不增加欢迎页、宣传文案或装饰性说明。

## 导航与搜索

- 工具是用户已知且数量有限的固定集合，只通过侧边栏直接切换。
- 侧边栏展开宽度固定为 224pt，不允许拖宽；允许通过标题栏位置的单一功能按钮折叠和展开。
- 侧边栏在列表上方显示一次“OneBox”，作为应用身份锚点；内容区不得再次显示品牌名。当前没有品牌菜单，不添加下拉箭头或伪交互。
- 展开时折叠按钮位于侧边栏右上方；折叠后展开按钮移到主区左上方，避开窗口控制按钮。
- 侧边栏与主内容区只通过 `sidebar` 和 `background` 的明度差分区，不绘制贯穿全高的分隔线、内阴影或渐变边缘。
- 当前导航项只使用一层中性选中底，不使用 `border-left`、强调色竖线、描边、阴影或多层 highlight。
- 当前范围不实现全局搜索、命令面板、搜索索引、搜索状态、结果页或空结果状态。
- 不在侧边栏常驻显示快捷键提示。快捷键如有真实需求，通过 macOS 菜单命令提供。

## 外观范围

- 当前产品只以浅色外观作为默认和正式验收基准，不跟随系统切换到深色。
- 深色仅保留语义 token、预览入口和相同的布局结构，属于后续优化占位；当前不承诺视觉完成度。
- OneBox 品牌标识拥有已批准的浅色和深色 PNG master；AppIcon 使用完整图形，侧栏 24pt 标识则用透明底 SwiftUI optical mark，按当前 Design System palette 选择对应外盒与内核 token，不叠加宿主效果。正式来源、尺寸分工和生成规则见 [`docs/assets/brand/README.md`](assets/brand/README.md)。
- 宿主 UI 颜色必须使用 Design System 提供的语义 token；ASCII 工坊可以把固定领域配色写入输出画布，但不得用它们改变宿主控件。
- 下表是浅色配色契约，`LightPaletteHex` 是运行时实现，`LightPaletteTests` 防止实现意外偏离契约；未获得明确设计决定不得修改、替换或增加局部色值。
- 禁止使用透明度从现有颜色派生常驻文字、背景、边框或选中态；需要新颜色时必须先定义用途明确的语义 token。
- 应用根视图必须用 `accent` 设置全局 tint，禁止出现未定义的系统蓝色强调控件。
- 后续完善深色时，不得改变尺寸、边距、边框宽度、信息层级或文字换行。

### 锁定的浅色配色

| Token | Hex | 固定用途 |
| --- | --- | --- |
| `background` | `#FBFBFA` | 主内容画布 |
| `sidebar` | `#F0F0EE` | 侧边栏底色 |
| `surface` | `#FFFFFF` | 卡片、输入和独立内容表面 |
| `surfaceElevated` | `#EEEEEC` | 悬停或二级控件表面 |
| `selection` | `#E4E4E2` | 唯一导航选中底色 |
| `border` | `#D8D8D5` | 必要的组件内分隔线和描边，不用于宿主分区 |
| `textPrimary` | `#1B1C1E` | 标题、正文和主标签 |
| `textSecondary` | `#66676A` | 必要的次级信息与功能图标 |
| `accent` | `#BC4535` | 主操作、焦点和品牌强调 |
| `brandMarkHost` | `#3569CE` | 浅色品牌 optical mark 的外盒和五官 |
| `brandMarkCore` | `#FFF1D6` | 浅色品牌 optical mark 的内核 |
| `brandGradientStart` | `#3B6FD8` | ASCII 工坊 OneBox 输出预设数字 `1` 的渐变起点 |
| `brandGradientMiddle` | `#8A5CBF` | ASCII 工坊 OneBox 输出预设数字 `1` 的渐变中点 |
| `brandGradientEnd` | `#BC4535` | ASCII 工坊 OneBox 输出预设数字 `1` 的渐变终点 |
| `positive` | `#087A4B` | 成功与正向数据 |
| `negative` | `#B42318` | 错误、危险和负向数据 |
| `warning` | `#8F6400` | 警告状态 |
| `info` | `#1C587B` | 信息状态文字 |
| `infoSurface` | `#E8F3F9` | 信息状态背景 |

- `textPrimary` 与 `textSecondary` 在 `background`、`sidebar`、`surface` 和 `selection` 上均须保持清晰可读。
- `accent`、`positive`、`negative`、`warning` 和 `info` 只表达语义，不作为装饰色或大面积背景。
- `brandGradientStart`、`brandGradientMiddle` 和 `brandGradientEnd` 只允许用于 ASCII 工坊的 OneBox 输出预设及其占位预览，不再驱动侧栏品牌标识；`OneBox` 字标保持 `textPrimary`。该渐变不得扩展到导航或按钮，也不得添加发光、阴影或宿主动画。
- 状态不能只依靠颜色传达；必须同时由文字、数值符号或控件状态表达。
- 任何已批准的配色变更必须同时更新本表、`LightPaletteHex`、`LightPaletteTests` 和可复现的浅色验收证据，不允许只改其中一处。

## 文字与阅读成本

- 默认删除解释型小字。只有删除后会造成操作歧义、数据误读或风险时，才允许显示辅助文字。
- 当前工具已经由侧边栏选中态明确标识，主内容区不再重复页面标题；不添加 eyebrow、欢迎语、功能描述、显而易见的排序说明或无行动价值的更新时间。
- 元数据只保留会改变数据含义的单位、市场、状态或时间；同一信息不得在标题、正文和提示中重复。
- 必要但低频的解释放入帮助入口、tooltip 或辅助功能标签，不常驻占用界面。
- 提醒文案使用最短可行动表达，例如“腾讯控股 · HK$ 630 提醒”。

## 字体

- 统一使用 macOS 系统字体 SF Pro；不引入 Inter、Roboto 或营销展示字体。
- 字体角色由 Design System 集中定义，页面不得临时指定字号、字重或字间距。

| 角色 | 规格 | 用途 |
| --- | --- | --- |
| Sidebar title | 20pt / Semibold | 左上角 OneBox 应用身份 |
| Section title | 14pt / Semibold | 必要的内容分组 |
| Body / Control | 13pt / Regular 或 Medium | 列表、按钮、导航 |
| Essential metadata | 12pt / Regular | 不可省略的单位或状态 |
| Key metric | 20pt / Semibold | 行情卡片中的主要数值 |

- 可见文字不得小于 12pt。
- 行情、价格、百分比和其他对齐数字必须使用 `.monospacedDigit()`。
- 同一行文字按文字基线对齐；不得通过肉眼添加单点 `offset` 修正。

## 网格与对齐

- 基础间距网格为 8pt；只允许使用 4、8、12、16、24、32 和 48pt。
- 默认窗口为 1048×648pt（比例 1.617，接近黄金比例）。窗口允许缩放，但必须始终锁定 1048:648；最小高度为 556pt，最小宽度由同一比例计算为约 899pt。
- 宿主默认几何 token：侧边栏宽 224pt、主内容内边距 24pt、侧边栏行高 36pt、数据行高 56pt。
- 侧边栏外边距固定为 12pt，品牌行与导航再内缩 8pt。品牌行使用 `24pt 标识 + 8pt 间距 + OneBox`，导航文字仍从 20pt 左边线开始；不得为单行内容单独微调。
- OneBox 品牌行位于标题栏控制区下方 16pt；工具列表在品牌行下方再留 16pt，不与标题挤在同一行。
- 同一层级的标题、卡片、列表和提示必须共享同一条左边线和右边线。
- 表格和行情列表必须使用稳定列定义；名称列左对齐，价格和涨跌列右对齐，操作列居中。
- 等宽元素必须由父容器统一约束，不在每个子视图重复写尺寸。
- 禁止用负 padding、任意 `offset` 或透明占位字符补对齐；需要特殊对齐时使用 `Grid`、frame、alignment guide 或基线对齐。

## 图标

- 一级导航采用纯文字排版，不显示图标。品牌图形不承担操作；侧栏折叠按钮是当前唯一允许的宿主常驻功能图标。工具内图标必须对应打开、播放、参数和导出等真实操作。
- 同一屏默认不为每条内容重复配图标。文字已经足以识别对象时，必须使用纯文字。
- 功能图标统一使用 SF Symbols；不使用 emoji、混合来源图标或把文字当作功能图标。
- 常规图标使用 16×16pt 光学框，放入统一的 24×24pt 容器；同一导航或工具栏内使用相同字重和渲染模式。
- 图标必须按光学中心对齐，不以不同 symbol 的原始边界直接决定位置。
- 图标按钮共享统一尺寸和内边距；纯图标按钮必须提供辅助功能名称。

## 组件边界

- 宿主当前拥有窗口和侧边栏；跨工具全局操作或标准状态页出现真实需求时也由宿主拥有。当前工具只由侧边栏选中态标识，内容区不重复标题。
- 工具模块提供内容区域和领域操作。创作类工具允许紧凑上下文操作条和内容区内的停靠检查器；检查器必须可收起，并支持 Escape 与辅助功能 escape 关闭。
- 工具模块不得增加全局搜索、第二套导航或全局配色；只允许在工具可见时生效的上下文快捷键。

## ASCII 工坊画布

- 工具由紧凑操作条、单层画布和默认展开的 248pt 右侧停靠检查器组成；检查器使用方形画布右侧原本闲置的宽度，并可从操作条或自身关闭按钮收起。
- 操作条不绘制外层卡片、背景或描边，依靠 8pt 组内间距和 16pt 组间间距建立层级；控件统一使用 13pt Control 字体。三个固定画布比例必须以单选分段控件直接显示，配色使用单层菜单，不能再套一层 Picker 子菜单；只有导出保留实心主操作样式。
- 画布只允许 1:1、16:9 和 9:16 三个固定比例，始终在剩余工作区内完整适配；画布外不再增加第二层容器。检查器只改变预览可用区域，不改变输出比例或导出几何。
- 透明输出时，画布用 `surface` 与 `surfaceElevated` 组成中性棋盘格；棋盘格只表示透明，不进入导出。
- 画布允许拖动平移、滚轮或触控板捏合缩放和双击重置，同时提供可聚焦的“重置视图”按钮。拖动必须按连续指针位置计算，画面与指针同向、等距离移动；缩放必须区分精确触控板增量与离散鼠标滚轮，并以当前指针位置为锚点，不能在缩放过程中向画布中心漂移。画布自身可聚焦；焦点位于画布时，方向键平移、`+`/`-` 缩放、`0` 重置、空格播放或暂停。裸空格不得注册为窗口级快捷键，字符输入框必须能输入空格。
- 等宽状态只用于字符集输入、网格或输出尺寸等确需对齐的内容，不把宿主整体改为终端风格。
- 动画状态必须同时用按钮名称和播放/暂停图形表达；减少动态效果开启时默认静态，用户显式播放后才启动创作动画。

## 验收

每次 UI 变更交付前必须验证：

1. 在默认窗口和最小支持窗口下检查浅色外观。
2. 检查深色占位没有破坏既定几何结构；深色视觉精修不属于当前验收范围。
3. 对照锁定表检查浅色取值，确认没有系统蓝色、局部硬编码色或通过透明度派生的常驻颜色。
4. 检查图标光学中心、文字基线、共同边线、等高行和等宽列。
5. 检查数字使用等宽字形并按列右对齐。
6. 删除所有不影响理解或操作的辅助文字。
7. 确认没有截断、重叠、意外换行或水平滚动。

未完成上述检查的 UI 变更不得视为完成。
