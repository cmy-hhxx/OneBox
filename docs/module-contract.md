# 工具模块契约

工具通过宿主组合根中的类型安全注册值进入 OneBox，不通过 JSON 配置或磁盘扫描发现：

```swift
ToolRegistration(id: id, displayName: name, activation: activation) { context in
    ToolScene(context: context)
}
```

确切 Swift 类型在第一个端到端竖切中定义。注册接口只需要表达身份、展示名称、激活时机和构造方式；存储、网络客户端、日志器或内部状态不得暴露给宿主。

## 激活

当前只有两种激活时机：

| 激活 | 使用场景 |
| --- | --- |
| `onOpen` | 用户第一次打开工具；默认选择 |
| `onAppLaunch` | 宿主启动后立即运行，仅用于确实需要全局监听的工具 |

未激活工具不得发起业务 I/O。轮询间隔等调度细节属于工具实现和用户设置，不进入注册接口。

## 依赖

- 宿主在组合根构造工具并注入其真实需要的接口。
- 平台能力必须通过 adapter 注入；工具不得直接查找宿主或全局容器。
- 测试通过相同接口注入本地 stand-in 或测试 adapter。
- 工具不得导入另一个工具。

## 生命周期

1. 同一工具默认最多存在一个活动实例。
2. 重复打开不得重复注册全局监听器。
3. 关闭工具必须停止它拥有的定时器、订阅和可取消任务。
4. 只有明确属于宿主的后台任务可以跨越工具关闭。
5. 工具失败必须返回可分类错误，不得终止宿主进程。

优先用 SwiftUI 的 scene、view 和 task 生命周期满足这些不变量，不额外发明 `activate` 或 `deactivate` 包装层。

## 数据

- 每个工具只访问自己的存储命名空间。
- 当前支持范围只实现当前数据格式；格式变化时同步修改所有读写路径并删除旧实现，不写 migration 或 fallback。
- 开发期旧数据直接重置。该规则不授权静默删除已经承诺保留的用户数据。
- 宿主不解析工具业务数据。

## UI

宿主拥有窗口、导航、工具标题、全局命令、权限提示和标准状态页。工具只拥有内容区域和领域交互，不定义全局字体、颜色、间距尺度或窗口级快捷键。

## 新增工具

1. 实现一个满足本契约的工具模块。
2. 在宿主组合根注册一次。
3. 通过生命周期和依赖隔离测试。
4. 确认移除该注册后，宿主与其他工具仍能构建和运行。
