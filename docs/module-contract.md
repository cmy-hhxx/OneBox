# 工具模块契约

本文件定义真实工具业务接入时必须满足的接口与生命周期契约，不是当前实现进度表。当前已实现与未实现能力以[架构文档的状态表](architecture.md#当前实现)为准；没有对应代码和验证的条目不得对外宣称为现有保证。

工具通过宿主组合根中的类型安全注册值进入 OneBox，不通过 JSON 配置或磁盘扫描发现：

```swift
ToolRegistration(
    id: id,
    displayName: name
) {
    ToolScene()
}
```

注册接口只表达身份、展示名称和构造方式；存储、网络客户端、日志器或内部状态不得暴露给宿主。异构 SwiftUI 内容只在该静态注册接缝做类型擦除。

没有依赖的工具可以公开静态注册值。工具首次需要真实依赖时，改为公开窄 `makeRegistration(...)` factory：应用组合根只传入跨模块的平台能力或配置，工具模块在内部组装 client、store 和 model，再由注册 closure 捕获结果。不得把依赖集中到通用 context 或全局容器。

## 激活

- 当前所有工具只有 `onOpen` 语义：用户选中工具后才构造内容；未打开工具不得发起业务 I/O。
- 当前注册接口不声明宿主尚未实现的启动激活策略。

轮询间隔等调度细节属于工具实现和用户设置，不进入注册接口。第一个需要随应用启动的真实工具落地时，必须在同一变更中引入最小激活策略、宿主启动调度和生命周期测试，不能先暴露宿主无法兑现的注册状态。

## 依赖

- 应用在组合根调用工具 module factory，并注入其真实需要的跨模块接口。
- 平台能力必须通过 adapter 注入；工具不得直接查找宿主或全局容器。
- 测试通过相同接口注入本地 stand-in 或测试 adapter。
- 工具不得导入另一个工具。

## 生命周期

以下条目是包含真实任务、监听或业务状态的工具的验收条件，不表示 Runtime 当前已经提供通用生命周期管理器：

1. 同一工具默认最多存在一个活动实例。
2. 重复打开不得重复注册全局监听器。
3. 关闭工具必须停止它拥有的定时器、订阅和可取消任务。
4. 只有明确属于宿主的后台任务可以跨越工具关闭。
5. 工具失败必须返回可分类错误，不得终止宿主进程。

优先用 SwiftUI 的 scene、view 和 task 生命周期满足这些不变量，不额外发明 `activate` 或 `deactivate` 包装层。

## 数据

- 每个工具只访问自己的存储命名空间。
- 当前支持范围只实现当前数据格式；格式变化时同步修改所有读写路径并删除旧实现，不写 migration 或 fallback。
- 开发期旧数据直接重置。该规则不授权静默删除已经承诺保留的用户数据。
- 宿主不解析工具业务数据。

## UI

宿主拥有窗口、导航、工具标题、全局命令、权限提示和标准状态页。工具拥有内容区域、领域交互和内容区内部的滚动容器，不定义全局字体、颜色、间距尺度或窗口级快捷键。宿主和工具都必须遵守[设计规范](design.md)；工具不得增加全局搜索、第二套导航或常驻解释型小字。

未接入的能力默认只显示“待接入”，不得放置没有真实行为的输入框、按钮、列表或示例数据。已经完成的独立竖切可以显示其真实交互，但不得让界面暗示行情、提醒或其他上游能力已经接入。

## 新增工具

1. 实现一个满足本契约的工具模块。
2. 在宿主组合根注册一次。
3. 通过生命周期和依赖隔离测试。
4. 确认移除该注册后，宿主与其他工具仍能构建和运行。
