# ADR-0007: 由可见工具拥有股票看盘工作生命周期

- Status: Accepted
- Date: 2026-08-28

## Context

股票看盘需要打开数据库、恢复缓存、访问公开行情源并按间隔刷新。OneBox 的 registration 本身只是静态目录值，未选中的工具不应在应用启动时产生业务 I/O。原独立应用的浮窗、菜单栏和后台常驻模型也不属于 OneBox 的支持范围。

生命周期必须同时满足两点：工具可见时能恢复和刷新；内容离屏后不能继续联网，并且在关闭数据库前不能丢失已接受的自选或提醒设置。

## Options considered

### 应用启动时常驻 worker

切换工具时无需重建状态，但所有用户每次启动都会开库和联网，并需要宿主后台调度、应用隐藏策略和新的常驻运行入口。

### 宿主通用激活层

Host 可以向所有工具广播 active/inactive，但当前只有股票看盘需要该接缝；预建通用状态机会扩大 `ToolRegistration` 接口。

### 可见 SwiftUI 内容拥有工作

股票看盘视图的结构化 task 在挂载后启动，在离屏时取消；工具内部负责排空写入和关闭资源，不向 Host 暴露业务生命周期。

## Decision

- `StockWatchModule.makeRegistration(platform:)`、内容 factory 和 bootstrap 构造保持无业务 I/O；它们不打开数据库、不搜索、不刷新。
- 宿主选中并挂载股票看盘内容后，视图 task 才打开本地数据库、恢复缓存与设置，再启动首次刷新和可见期间的刷新循环。
- 切换到其他工具使内容离屏时，取消搜索、首次刷新、循环刷新、当前刷新批次、提醒消失任务和声音。网络任务必须保留取消点和超时。
- 停止新工作后，等待已经排队的自选写入，flush 待保存提醒设置，再关闭 SQLite。再次挂载必须先等待前一次 shutdown 完成，不能让 close 与 reopen 竞态。
- 打开或恢复失败时不创建降级内存库，也不启动网络；在原位置展示可重试的本地错误。
- “可见”由股票看盘内容是否挂载定义。窗口被其他窗口遮挡或仅失去焦点不等于内容离屏。
- 不增加宿主启动后台激活、独立浮窗、置顶、鼠标穿透、菜单栏、全局快捷键、登录启动或常驻后台监控。提醒只存在于可见 OneBox 内容和本地声音，不升级为系统通知。

## Consequences

### Positive

- 未选择股票看盘时不打开其数据库，也不发起行情请求。
- task 所有权、取消、flush 和 close 集中在工具内部，Host 不需要理解行情状态。
- 重新进入得到新的数据库和 store 实例，旧任务不会继续修改新会话。

### Negative

- 每次离屏再进入都需要重新开库和恢复本地状态。
- 离屏期间没有刷新或提醒；重新进入后看到的数据可能先以缓存和 stale 状态出现。
- 仅遮挡、失焦或最小化而 SwiftUI 内容仍挂载时，本 ADR 不保证停止；若产品要把窗口可见性纳入语义，需要真实窗口接缝、测试和后续决策。
